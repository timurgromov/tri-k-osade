# Зов знамен

Три миссии браузерной головоломки. [Играть](https://timurgromov.github.io/tri-k-osade/).

[Ранняя примерка звука лучников](https://timurgromov.github.io/tri-k-osade/archers-audio.html).

В репозитории хранится готовая сборка для GitHub Pages. [Лицензии библиотек](THIRD_PARTY_NOTICES.md).

## Музыка и звуковые эффекты

Фон первых двух миссий
собран из петель RandomMind, финал использует марш Eldritch Grim. Треки
нормализованы примерно до −24 LUFS до регулировки в игре и сжаты в MP3.

| Миссия | Файл | Источник CC0 |
| --- | --- | --- |
| Лесные ворота | `music/bards-loop.mp3` | RandomMind, [Medieval: The Bard's Tale](https://opengameart.org/content/medieval-the-bards-tale) |
| Щитовая застава | `music/tower-inn.mp3` | RandomMind, [Medieval: The Old Tower Inn](https://opengameart.org/content/medieval-the-old-tower-inn) |
| Каменный рубеж | `music/epic-march.mp3` | Eldritch Grim, [Epic March Loop](https://opengameart.org/content/epic-war-loop) |
